# zyf 图像与视频目录加载保存节点

一套 ComfyUI 自定义节点，专门用于**批量目录级**图像/视频的加载与保存，配合顺序自动排队机制（与 zyf-video 分段计划同款），无需在执行队列设置总数即可逐个处理文件；统一的目录路径浏览按钮、实时进度显示；视频节点支持 GPU 硬件编解码 (NVDEC/NVENC)、强制尺寸缩放、工作流元数据嵌入。

---

## 节点总览

### 图像处理节点

| # | 节点名称 | 显示名 | 说明 |
|---|---|---|---|
| 1 | `zyf_ImageDirectoryLoader` | 图像目录加载器 | 从目录批量加载图像，顺序自动排队、进度显示、目录总数即时刷新 |
| 2 | `zyf_ImageDirectorySaver` | 图像目录保存器 | 批量保存图像，保持目录结构 / 内容哈希命名，占位图像自动跳过 |
| 3 | `zyf_ImageSaveWithPreview` | 图像保存与预览 | 保存图像并输出预览图（单张或批量帧序列） |
| 4 | `zyf_ImageBatchMulti` | 多图像批量合并 | 按 `inputcount` 动态增减 image\_1..N 端口，一键合并成批次 |
| 5 | `zyf_MaskBatchMulti` | 多遮罩批量合并 | 同上，批量合并 MASK 端口 |

### 视频处理节点

| # | 节点名称 | 显示名 | 说明 |
|---|---|---|---|
| 6 | `zyf_VideoDirectoryLoader` | 视频目录加载器 | 目录/单视频加载，GPU 硬解 + Lanczos 缩放 + 强制尺寸 + 顺序自动排队 |
| 7 | `zyf_VideoDirectorySaver` | 视频目录保存器 | 逐帧流式写视频，GPU 硬编 (NVENC)，CRF 随编码自动切换，工作流元数据嵌入 mp4 |
| 8 | `zyf_VideoInfoUnpack` | 视频信息解包 | 将「视频信息」字典拆成 帧率 / 总帧数 / 宽度 / 高度 四个独立端口 |

## 核心特性

### 顺序加载（无需写总数）
所有目录加载器都内置与 zyf-video 分段计划一致的自动排队机制：
- 节点顶部实时显示进度 `已加载 / 总数`
- 目录路径或起始索引变化时自动重置
- 添加/修改目录后立即刷新总数量（后端 `/zyf_image_directory/count_directory_files` 接口）
- 前端单调索引保护，杜绝重复或乱序处理

### 目录总数即时显示
- 每次修改目录路径（或扩展名过滤、递归开关）时，前端防抖调用后端计数
- 3 秒内重复操作只请求一次（防抖），无需等待工作流开始运行

### 自然排序（按名称）
- 文件名中的数字按**数值**比较（例如 `2` < `10`），与 Directory Opus / Windows 资源管理器默认「按名称 (正序)」一致
- 忽略大小写

### GPU 硬件加速（视频节点）
- **解码**：自动检测 ffmpeg `-hwaccel cuda`（NVDEC），失败自动回退 CPU
- **编码**：自动检测 `h264_nvenc` / `hevc_nvenc`，失败自动回退 `libx264` / `libx265`
- 启动时打印检测结果，无需用户手动配置

### 幂等保存（防重复文件）
- **图像目录保存器** 未连接相对路径时：`image_<MD5前10位>.png`
- **视频目录保存器** 未连接相对路径时：`video_<MD5前10位>.mp4`
- 输出文件已存在即跳过，避免多次运行重复写入

### 元数据嵌入（视频目录保存器）
- 开启「保存元数据」后，使用 ffmetadata 文件方式将 ComfyUI `prompt` 与 `workflow` 写入 mp4
- 用 ComfyUI 「Load」拖入该 mp4，可自动还原当时作业的完整工作流（与 zyf-video 保存视频一致）

## 节点详细说明

### 1. 图像目录加载器 `zyf_ImageDirectoryLoader`

**输入选项：**
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 目录路径 | STRING | `""` | 图像目录，支持相对（ComfyUI 根目录）或绝对路径，右侧「浏览目录...」按钮快速选择 |
| 起始索引 | INT | `0` | 从第几张开始（0 = 第 1 张）。重跑始终从该值开始，需断点续传时手动修改 |
| 排序方法 | 下拉 | `按名称` | 按名称（自然排序）/ 按数字 / 按修改时间 |
| 递归搜索子目录 | BOOLEAN | `True` | 是否扫描子目录 |
| 文件扩展名过滤 | STRING | `""` | 逗号分隔，如 `jpg,png`。留空 = 所有支持格式 |
| 加载失败跳过 | BOOLEAN | `True` | 损坏/无效文件是否跳过 |
| 转换为RGBA | BOOLEAN | `False` | 是否转为 RGBA 并带 alpha=255 |

**输出：**
| 端口 | 类型 | 说明 |
|---|---|---|
| 图像 | IMAGE | `(B,H,W,C)` 张量 |
| 相对路径 | LIST | 相对路径字符串列表 |
| 文件名 | STRING | 当前单张文件名 |

---

### 2. 图像目录保存器 `zyf_ImageDirectorySaver`

**输入端口：**
| 端口 | 类型 | 必需 | 说明 |
|---|---|---|---|
| 图像批量 | IMAGE | ✅ | 单张或批量图像 |
| 相对路径列表 | LIST | ❌ | 连接时按原目录结构+原文件名保存；不连接则按内容哈希命名 |

**选项：**
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 输出路径 | STRING | `"output"` | 保存目录 |
| 覆盖已存在文件 | 下拉 | `否` | 否 / 是 |
| 保存格式 | 下拉 | `原格式` | 原格式 / jpg / png / webp |
| 压缩质量 | INT | `90` | JPG/WEBP 压缩质量（1-100）；PNG 无效 |
| 文件名 | STRING | `"image_####"` | 格式模板，`####` 替换为序号；仅在相对路径未连接时生效 |

---

### 3. 图像保存与预览 `zyf_ImageSaveWithPreview`

仅输出 `预览图像` 单个端口（不再输出保存路径和保存数量）。参数名与「图像目录保存器」一致：输出路径、覆盖已存在文件、保存格式、压缩质量、文件名（输入端口）。

---

### 4. 多图像批量合并 `zyf_ImageBatchMulti` / 多遮罩批量合并 `zyf_MaskBatchMulti`

- 参数 `inputcount`：调整输入槽位数量
- 按钮 **「Update inputs」**：按 inputcount 动态增减 `image_1`..`image_N`（或 `mask_1`..`mask_N`）
- `image_1 / mask_1` 为必填，其余为可选（空槽位自动跳过）

---

### 5. 视频目录加载器 `zyf_VideoDirectoryLoader`

**输入选项：**
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 目录路径 | STRING | `""` | 目录或单视频文件 |
| 起始索引 | INT | `0` | 从第几个视频开始（0 = 第 1 个） |
| 排序方法 | 下拉 | `按名称` | 按名称（自然排序）/ 按数字 / 按修改时间 |
| 递归搜索子目录 | BOOLEAN | `True` | |
| 文件扩展名过滤 | STRING | `""` | 逗号分隔 |
| 加载失败跳过 | BOOLEAN | `True` | |
| **强制尺寸** | 下拉 | `禁用` | 见下方「强制尺寸规则」 |
| 自定义短边 | INT | `512` | 强制尺寸 =「自定义短边」时显示 |
| 自定义长边 | INT | `832` | 强制尺寸 =「自定义长边」时显示 |
| 自定义宽度 | INT | `480` | 强制尺寸 =「自定义宽高」时显示 |
| 自定义高度 | INT | `480` | 强制尺寸 =「自定义宽高」时显示 |
| 图像尺寸倍数 | 下拉 | `无` | 无 / 8 / 16 / 32 / 64 / 128 / 256 / 512（禁用时不显示） |

**强制尺寸规则：**
| 选值 | 行为 |
|---|---|
| 禁用 | 保持原始尺寸（仅规范化为偶数）；所有子选项**不显示** |
| 自定义短边 | 短边对齐「自定义短边」，另一边等比；显示 自定义短边 + 图像尺寸倍数 |
| 自定义长边 | 长边对齐「自定义长边」，另一边等比；显示 自定义长边 + 图像尺寸倍数 |
| 自定义宽高 | 直接指定宽 / 高，填 0 则该边等比；显示 自定义宽度 + 自定义高度 + 图像尺寸倍数 |
| `480x?` / `?x480` / `480x480` / `832x?` / `?x832` / `832x832` | 预设固定尺寸；仅显示 图像尺寸倍数 |

**输出：**
| 端口 | 类型 | 说明 |
|---|---|---|
| 帧序列 | IMAGE | `(B,H,W,C)` |
| 音频 | AUDIO | `{waveform, sample_rate}` 或空 lambda |
| 视频信息 | `ZYF_DIR_VIDEO_INFO` | 字典：`{frame_rate, total_frames, width, height}` → 交给视频信息解包 |
| 相对路径 | STRING | 当前视频相对于扫描目录的路径，可直接连视频目录保存器 |

| 视频信息 | `ZYF_DIR_VIDEO_INFO` | → | 帧率 | FLOAT |

| | | → | 高度 | INT |

### 7. 视频目录保存器 `zyf_VideoDirectorySaver`

**输入端口：**
| 端口 | 类型 | 必需 | 说明 |
|---|---|---|---|
| 图像 | IMAGE | ✅ | 帧序列 `(B,H,W,C)` 或单帧 `(H,W,C)` |
| 音频 | AUDIO | ❌ | 连了就 AAC 192kbps 合并进 mp4 |
| 相对路径 | STRING | ❌ | 连了 = 按原目录结构+原视频名保存；未连 = 内容哈希命名 |

**选项：**
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 帧率 | FLOAT | `32` | 左右微调，步长 1；整数显示整数，小数显示小数（无多余零） |
| 输出路径 | STRING | `"output"` | 保存目录，「浏览目录...」按钮选择 |
| 编码格式 | 下拉 | `H264` | H264 / H265；切换时若 CRF 仍为对侧默认值，自动切换成侧默认（H264=19 / H265=22） |
| 质量CRF | INT | `19` | H264 初值 19，H265 初值 22（用户修改过则不再跟随） |
| 保存元数据 | BOOLEAN | `True` | 嵌入 ComfyUI prompt + workflow 到 mp4（ffmetadata 文件方式，无命令行长度限制） |

- 像素格式：固定 `yuv420p`，用户不可见
- 编码：自动检测 NVENC（`-preset p4 -tune hq -cq CRF -rc vbr`），失败自动回退 CPU x264/x265
- 奇数尺寸：自动 pad 到偶数（yuv420p 兼容）
- 输出格式：一律 `.mp4`；若相对路径已有合法视频扩展名则保留，否则追加 `.mp4`
- 流式：逐帧转 uint8 并写入 ffmpeg stdin，峰值内存 ≈ 单张帧的张量 + uint8 副本

## 使用示例

### 示例 1：批量图像目录处理
```
[图像目录加载器] → [图像/扩散/后处理节点] → [图像目录保存器]
        └── 相对路径 ────────────────────────────→ 相对路径列表
```
- 点一次「Queue Prompt」自动按顺序逐个处理所有图像
- 节点顶部实时看到 `5 / 128` 之类的进度

### 示例 2：批量视频处理 + 传参给保存器
```
[视频目录加载器] → [帧序列处理] → [视频目录保存器]
    |   音频     ─────────────────→ 音频
    |   视频信息 → [视频信息解包] → 帧率 → 视频目录保存器（帧率）
    └── 相对路径 ──────────────────────────────────→ 相对路径
```
- 视频目录加载器和保存器均支持 GPU 硬解/硬编
- 相对路径直连 = 按原目录结构+原视频文件名输出 mp4
- 视频信息解包把帧率传到保存器（保持原帧率重编码，也可以用 Constant 值）

## 已知兼容说明

- **按名称排序**：使用 `_zyf_natural_key`（忽略大小写 + 数字按数值比较），与 Directory Opus / Windows Explorer 默认一致
- **前端视频播放器**：视频目录加载器不内置视频预览；若需预览可将输出端口连 ComfyUI 原生 Video Preview 或 zyf-video 的播放器节点
- **GPU 检测**：启动节点时才按需探测 `ffmpeg -hwaccels` / `ffmpeg -encoders`，探测结果全局缓存一次
- **工作流跨版本迁移**：若旧工作流仍引用已删除节点（条件图像保存器、条件图像目录保存器、视频自动合并器、批量音频提取合并器、视频转换分割器），请手动替换为当前节点组合
